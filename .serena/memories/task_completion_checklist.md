# タスク完了時のチェックリスト

## コード変更後の確認事項

### 1. 動作確認
- [ ] Webブラウザでindex.htmlを開いて動作確認
- [ ] 主要機能（ゲート配置、接続、シミュレーション）の動作確認
- [ ] エラーがないかブラウザ開発者ツールのConsoleを確認
- [ ] レスポンシブデザインの確認（デスクトップ・モバイル）

### 2. コード品質
- [ ] JavaScript構文エラーがないか確認
- [ ] CSS構文エラーがないか確認
- [ ] 変数名・関数名が命名規則に従っているか確認
- [ ] コメントが適切に記述されているか確認

### 3. ユーザビリティ
- [ ] UI操作が直感的で分かりやすいか確認
- [ ] エラーメッセージが適切に表示されるか確認
- [ ] パフォーマンスに問題がないか確認
- [ ] アクセシビリティ（キーボード操作等）の確認

### 4. バージョン管理
- [ ] 意味のあるコミットメッセージを記述
- [ ] 必要に応じてバージョン番号の更新
- [ ] 変更内容をCLAUDE.MDに記録（必要に応じて）

## 注意事項
- **自動テスト**: 実装されていないため手動確認必須
- **linting**: 自動化されていないため目視確認
- **依存関係**: 外部ライブラリなしのため互換性問題は少ない
- **ブラウザ対応**: モダンブラウザ（Chrome, Firefox, Safari, Edge）での確認推奨
