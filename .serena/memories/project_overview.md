# Logic Circuit Simulator - プロジェクト概要

## プロジェクトの目的
高校生向けの論理回路学習ツール。AND、OR、NOT回路を視覚的に学べるWebベースのシミュレータ。ドラッグ&ドロップで回路を配置し、マウスで接続して、実際の動作をステップ実行で確認できる教育ツール。

## 技術スタック
- **HTML5**: セマンティックマークアップ、Canvas API
- **CSS3**: レスポンシブデザイン、アニメーション効果
- **JavaScript (ES6+)**: 
  - Canvas APIによる回路描画
  - ドラッグ&ドロップAPI
  - イベント処理
  - 論理演算処理
- **デプロイメント**: 静的サイト（GitHub Pages対応）

## 主要機能
- 回路コンポーネント配置（AND、OR、NOT、INPUT、OUTPUT）
- ドラッグ&ドロップによる回路配置・移動
- マウスクリックによる回路間接続
- シミュレーション実行とステップ実行
- 信号値のリアルタイム表示
- 回路保存・読込機能
- テンプレート回路（半加算器、全加算器等）
- 動的真理値表生成
- モバイル対応レスポンシブデザイン

## 教育的価値
- 直感的なユーザーインターフェース
- 回路動作の視覚的フィードバック
- ステップバイステップの学習支援
- 真理値表、ベン図、回路図の統合表示
